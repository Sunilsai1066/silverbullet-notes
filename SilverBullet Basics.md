# Markdown Cheat Sheet

A quick reference for writing notes in SilverBullet.

---

# Headings

```markdown
# Heading 1

## Heading 2

### Heading 3

#### Heading 4

##### Heading 5

###### Heading 6
```

---

# Bold / Italic

```markdown
**Bold**

*Italic*

***Bold + Italic***

~~Strikethrough~~
```

---

# Bullet Lists

```markdown
- Kafka
- Docker
- Kubernetes
```

Nested lists:

```markdown
- Kafka
  - Producer
  - Consumer
```

---

# Numbered Lists

```markdown
1. Kafka
2. Redis
3. Docker
```

---

# Task Lists

```markdown
- [x] Install Traefik
- [x] Install Vaultwarden
- [ ] Install Grafana
```

---

# Inline Code

```markdown
Use `docker ps`
```

Example:
