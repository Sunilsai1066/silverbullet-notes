# [2390. Removing Stars From a String](https://leetcode.com/problems/removing-stars-from-a-string/)

## Problem

https://leetcode.com/problems/removing-stars-from-a-string/description/

### Testcase 1

```data
Input: s = "leet**cod*e"
Output: "lecoe"
```

### Testcase 2

```data
Input: s = "erase*****"
Output: ""
```

### Constraints

```data
1 <= s.length <= 10^5
s consists of lowercase English letters and '*'.
The operation above can be performed on s.
```

## Intution

The key observation is that every `'*'` removes **the closest non-star character to its left**. Since the most recently seen character is always the one that should be removed first, this is exactly the behavior of a **stack (LIFO)**.

Traverse the string from left to right:

- If the current character is a letter, push it onto the stack.
- If the current character is `'*'`, remove the top character from the stack.

After processing the entire string, the stack contains the final string in the correct order.

**In one line:** Use a stack to keep track of characters, popping the most recent character whenever a `'*'` is encountered.

## Algorithm

1. Initialize an empty stack.
2. Traverse each character in the string.
3. If the character is a letter, push it onto the stack.
4. If the character is `'*'`, pop the top element from the stack.
5. Join all characters remaining in the stack and return the resulting string.

## Code

```py
class Solution:
    def removeStars(self, s: str) -> str:
        stack = []
        for char in s:
            if char == "*":
                stack.pop()
            else:
                stack.append(char)
        return "".join(stack)
```

## Time Complexity

Let `n` be the length of the string.

Each character is processed exactly once.

- Push operation: `O(1)`
- Pop operation: `O(1)`

### Total Time Complexity

```
O(n)
```

## Space Complexity

In the worst case, the stack stores every character (when there are no stars until the end).

### Total Space Complexity

```
O(n)
```

## Key Takeaways

- When a problem repeatedly removes the **most recently added** element, think of a **stack**.
- Stack naturally models Last-In-First-Out (LIFO) behavior.
- Each character is pushed and popped at most once, giving an efficient linear-time solution.
