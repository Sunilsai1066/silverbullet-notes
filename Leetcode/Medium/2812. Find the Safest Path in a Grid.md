## Code

```py
class Solution:
    directions = [(0, 1), (0, -1), (1, 0), (-1, 0)]
    INF = float("inf")

    def isSafe(self, safeness_grid, threshold):
        rows = len(safeness_grid)
        queue, seen = deque([(0, 0)]), {(0, 0)}
        while queue:
            row, col = queue.popleft()
            if row == rows - 1 and col == rows - 1:
                return True
            for dx, dy in self.directions:
                r, c = row + dx, col + dy
                if (
                        0 <= r < rows and
                        0 <= c < rows and
                        (r, c) not in seen and
                        safeness_grid[r][c] >= threshold
                ):
                    queue.append((r, c))
                    seen.add((r, c))
        return False

    def markSafeness(self, safeness_grid, thief_queue):
        rows, level = len(safeness_grid), 1
        for r, c in thief_queue:
            safeness_grid[r][c] = 0
        while thief_queue:
            for _ in range(len(thief_queue)):
                row, col = thief_queue.popleft()
                for dx, dy in self.directions:
                    r, c = dx + row, dy + col
                    if 0 <= r < rows and 0 <= c < rows and safeness_grid[r][c] == self.INF:
                        safeness_grid[r][c] = level
                        thief_queue.append((r, c))

            level += 1

    def maximumSafenessFactor(self, grid: List[List[int]]) -> int:
        rows = len(grid)
        if grid[0][0] == 1 or grid[rows - 1][rows - 1] == 1:
            return 0
        thief_queue = deque()
        for r in range(rows):
            for c in range(rows):
                if grid[r][c] == 1:
                    thief_queue.append((r, c))
        safeness_grid = [[self.INF] * rows for _ in range(rows)]
        self.markSafeness(safeness_grid, thief_queue)
        low, high = 0, min(safeness_grid[0][0], safeness_grid[rows - 1][rows - 1])
        while low <= high:
            mid = (low + high) // 2
            if self.isSafe(safeness_grid, mid):
                low = mid + 1
            else:
                high = mid - 1
        return high

```


## Time Complexity

Let the matrix size be **n × n**.

- **Initial BFS:** `O(n²)`
  - Each cell is visited at most once while computing the safeness factor for every cell.

- **Binary Search:** `O(log n)`
  - The search space is `[0, 2n]` since the maximum possible safeness factor is `2n`.
  - `log(2n) = O(log n)`.

- **BFS inside Binary Search:** `O(n²)` per iteration
  - For each binary search step, we run a BFS to check whether a valid path exists for the current safeness threshold.

### Total Time Complexity

```
O(n²) + O(log n) × O(n²)
= O(n² + n² log n)
= O(n² log n)
```


## Space Complexity

**O(n²)**

- The queue used during BFS can hold up to `n²` cells in the worst case.
- The visited matrix (or equivalent data structure) also requires `O(n²)` space.

Therefore, the overall space complexity is:

```
O(n²)
```
