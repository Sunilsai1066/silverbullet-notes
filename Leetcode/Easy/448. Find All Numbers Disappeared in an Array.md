
### Testcase 2

```data
Input: nums = [1,1]

```

### Constraints

```data

1 <= nums[i] <= nums.length
```

# Solution 1: Hash Set

## Intution

The array should contain every number from `1` to `n`. By storing all existing numbers in a hash set, we can quickly determine which numbers are missing.

Traverse the expected range `1` to `n`:

- If a number exists in the set, it is present in the array.
- Otherwise, it is one of the disappeared numbers.

**In one line:** Store all numbers in a hash set and collect the numbers from `1` to `n` that are missing.

## Algorithm

1. Insert every element into a hash set.
2. Traverse numbers from `1` to `n`.
3. If a number is not present in the set, add it to the result.
4. Return the result.

## Code

```py
class Solution:
    def findDisappearedNumbers(self, nums: List[int]) -> List[int]:
        res = []
        unique = set(nums)

        for idx in range(1, len(nums) + 1):
            if idx not in unique:
                res.append(idx)

        return res
```

## Time Complexity

Creating the hash set takes:

```
O(n)
```

Traversing numbers from `1` to `n` takes:

```
O(n)
```

### Total Time Complexity

```
O(n)
```

## Space Complexity

The hash set may contain up to `n` distinct elements.

```
O(n)
```

# Solution 2: Negative Marking

## Intution

Since every number is guaranteed to lie within the range:

```
1 <= nums[i] <= n
```

each value can be treated as an index.

For every number:

- Convert it to its corresponding index.
- Mark that index as visited by making the value negative.

After processing the entire array:

- Every visited index becomes negative.
- Any index that remains positive was never visited.
- Therefore, its corresponding number is missing from the array.

This allows us to find all missing numbers without using extra space.

**In one line:** Use each value as an index and mark visited positions by negating them; indices that remain positive correspond to the missing numbers.

## Algorithm

1. Traverse every number in the array.
2. Convert the value into its corresponding index.
3. If that index has not been visited, negate its value.
4. Traverse the array again.
5. Every positive value indicates that its index + 1 is missing.
6. Add those numbers to the result.
7. Return the result.

## Code

```py
class Solution:
    def findDisappearedNumbers(self, nums: List[int]) -> List[int]:
        res = []

        for num in nums:
            idx = abs(num) - 1
            if nums[idx] > 0:
                nums[idx] = -nums[idx]

        for idx in range(len(nums)):
            if nums[idx] > 0:
                res.append(idx + 1)

        return res
```

## Time Complexity

The array is traversed twice.

### Total Time Complexity

```
O(n)
```

## Space Complexity

Only the output list is used. The input array itself is modified in-place.

Ignoring the output array (as is standard for LeetCode space analysis):

```
O(1)
```

If the output array is included:

```
O(k)
```

where `k` is the number of missing elements.

## Key Takeaways

- A hash set provides a simple linear-time solution using extra space.
- Whenever values are guaranteed to be within `1...n`, consider using them as indices.
- Negative marking is a common in-place technique for recording whether an index has been visited.
- Always use `abs(num)` since elements may already have been negated during traversal.
- Positive indices after traversal directly correspond to the missing numbers.
