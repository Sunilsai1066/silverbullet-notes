### Testcase 1

```data
Input: nums = [8,1,2,2,3]
Output: [4,0,1,1,3]
Explanation:
For nums[0]=8 there exist four smaller numbers than it (1,2,2,3).
For nums[1]=1 there exist no smaller numbers.
For nums[2]=2 there exists one smaller number (1).
For nums[3]=2 there exists one smaller number (1).
For nums[4]=3 there exist three smaller numbers (1,2,2).
```

# Solution 1: Brute Force

## Intution

For every number, simply count how many numbers in the array are smaller than it.

Traverse the entire array for each element and increment a counter whenever a smaller value is found.

Since every pair of elements is compared once, this straightforward approach works but is not optimal.

**In one line:** For each element, compare it with every other element and count how many are smaller.

## Algorithm

1. Create a result array.
2. For every element in the array:
   - Initialize a counter.
   - Traverse the entire array.
   - Increment the counter whenever a smaller number is found.
3. Store the count in the result array.
4. Return the result.

## Code

```py
class Solution:
    def smallerNumbersThanCurrent(self, nums: List[int]) -> List[int]:
        res = [0] * len(nums)

        for idx in range(len(nums)):
            count = 0
            for idy in range(len(nums)):
                if nums[idy] < nums[idx]:
                    count += 1
            res[idx] = count

        return res
```

## Time Complexity

For each of the `n` elements, we scan all `n` elements.

### Total Time Complexity

```
O(n²)
```

## Space Complexity

Only the output array is used.

```
O(n)
```

# Solution 2: Sorting + Hash Map

## Intution

After sorting the array, every number's **first occurrence** tells us exactly how many numbers are smaller than it.

For example:

```
nums = [8,1,2,2,3]

Sorted:
[1,2,2,3,8]
```

The first occurrence indices become:

```
1 → 0
2 → 1
3 → 3
8 → 4
```

Notice that the index of the first occurrence equals the number of elements smaller than that value.

Store these indices in a hash map, then traverse the original array and replace each number with its corresponding index.

**In one line:** Sort the array, record the first occurrence of each value, then use those indices as the counts of smaller numbers.

## Algorithm

1. Create a sorted copy of the array.
2. Traverse the sorted array.
3. Store the first occurrence index of every distinct number.
4. Traverse the original array.
5. Replace each number with its stored index.
6. Return the result.

## Code

```py
class Solution:
    def smallerNumbersThanCurrent(self, nums: List[int]) -> List[int]:
        temp = sorted(nums)
        temp_map, res = {}, []

        for idx, num in enumerate(temp):
            if num not in temp_map:
                temp_map[num] = idx

        for num in nums:
            res.append(temp_map[num])

        return res
```

## Time Complexity

Sorting the array takes:

```
O(n log n)
```

Building the hash map:

```
O(n)
```

Generating the result:

```
O(n)
```

### Total Time Complexity

```
O(n log n)
```

## Space Complexity

The sorted copy, hash map, and output array each require linear space.

### Total Space Complexity

```
O(n)
```

## Key Takeaways

- Brute force works by directly comparing every pair of elements.
- After sorting, the first occurrence index of a number equals the count of smaller numbers.
- Hash maps are useful for mapping sorted positions back to the original order.
- Whenever the answer depends on relative ordering rather than original positions, sorting is often a good approach.
