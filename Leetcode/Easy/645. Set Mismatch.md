# [645. Set Mismatch](https://leetcode.com/problems/set-mismatch/)

## Problem

https://leetcode.com/problems/set-mismatch/description/

### Testcase 1

```data
Input: nums = [1,2,2,4]
Output: [2,3]
```

### Testcase 2

```data
Input: nums = [1,1]
Output: [1,2]
```

### Constraints

```data
2 <= nums.length <= 10^4
1 <= nums[i] <= 10^4
```

# Solution 1: Hash Map (Counter)

## Intution

The array should contain every number from `1` to `n` exactly once. Since one number appears twice and another is missing, simply count the frequency of every number.

- The number with frequency `2` is the duplicate.
- The number with frequency `0` is the missing number.

Using a hash map (Counter) allows both to be identified in a single pass over the expected range.

**In one line:** Count the frequency of every number and identify the duplicate and the missing value.

## Algorithm

1. Count the frequency of every number using a `Counter`.
2. Traverse numbers from `1` to `n`.
3. If a number is absent from the map, it is the missing number.
4. If a number appears twice, it is the duplicate.
5. Return both values.

## Code

```py
class Solution:
    def findErrorNums(self, nums: List[int]) -> List[int]:
        res = [0] * 2
        nums_map = Counter(nums)

        for idx in range(1, len(nums) + 1):
            if idx not in nums_map:
                res[1] = idx
            elif nums_map[idx] == 2:
                res[0] = idx

        return res
```

## Time Complexity

Building the frequency map takes:

```
O(n)
```

Traversing numbers from `1` to `n` also takes:

```
O(n)
```

### Total Time Complexity

```
O(n)
```

## Space Complexity

The frequency map stores up to `n` distinct numbers.

```
O(n)
```

# Solution 2: Negative Marking

## Intution

Since every number lies in the range:

```
1 <= nums[i] <= n
```

each value can be treated as an index.

For every number:

- Visit its corresponding index.
- If that index has already been marked negative, the number has been seen before, so it is the duplicate.
- Otherwise, negate the value at that index to mark it as visited.

After processing the entire array:

- Any index that remains positive was never visited.
- Therefore, its corresponding number is the missing value.

This allows us to detect both numbers **without using extra space**.

**In one line:** Use each value as an index and mark visited positions by negating them; a second visit reveals the duplicate, while an unvisited index reveals the missing number.

## Algorithm

1. Traverse every number in the array.
2. Convert the number into its corresponding index.
3. If the value at that index is already negative, record the duplicate.
4. Otherwise, negate the value to mark it as visited.
5. Traverse the array again.
6. The index whose value remains positive corresponds to the missing number.
7. Return both values.

## Code

```py
class Solution:
    def findErrorNums(self, nums: List[int]) -> List[int]:
        res = [0] * 2

        for num in nums:
            idx = abs(num) - 1

            if nums[idx] < 0:
                res[0] = abs(num)
            else:
                nums[idx] = -nums[idx]

        for idx in range(len(nums)):
            if nums[idx] > 0:
                res[1] = idx + 1

        return res
```

## Time Complexity

The array is traversed twice.

```
O(n)
```

## Space Complexity

Only a few variables are used, and the input array is modified in-place.

```
O(1)
```

## Key Takeaways

- Frequency counting is the simplest solution but requires extra memory.
- Whenever values are guaranteed to be within `1...n`, consider using them as indices.
- Negative marking is a common in-place technique for detecting duplicates and missing elements.
- Taking `abs(num)` is necessary because some values may already have been negated during traversal.
