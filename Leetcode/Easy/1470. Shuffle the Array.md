### Testcase 1

```data
Input: nums = [2,5,1,3,4,7], n = 3
Output: [2,3,5,4,1,7]
Explanation:
Since x1=2, x2=5, x3=1, y1=3, y2=4, y3=7, the answer is [2,3,5,4,1,7].
```

### Testcase 2

```data
Input: nums = [1,2,3,4,4,3,2,1], n = 4
```

```data
Input: nums = [1,1,2,2], n = 2

```

### Constraints

```data
1 <= n <= 500
nums.length == 2 * n
1 <= nums[i] <= 10^3
```

# Solution 1: Extra Array

## Intution

The array is divided into two halves:

- First half: `x1, x2, ..., xn`
- Second half: `y1, y2, ..., yn`

The answer simply alternates elements from these two halves.

Create a new array of size `2n` and place:

- `xi` at index `2 * i`
- `yi` at index `2 * i + 1`

**In one line:** Create a new array and alternately place elements from the first and second halves.

## Algorithm

1. Create a result array of size `2n`.
2. Traverse the first half of the array.
3. Place `nums[i]` at index `2 * i`.
4. Place `nums[n + i]` at index `2 * i + 1`.
5. Return the result.

## Code

```py
class Solution:
    def shuffle(self, nums: List[int], n: int) -> List[int]:
        result = [0] * (2 * n)

        for i in range(n):
            result[2 * i] = nums[i]
            result[2 * i + 1] = nums[n + i]

        return result
```

## Time Complexity

The array is traversed once.

```
O(n)
```

## Space Complexity

An additional array of size `2n` is created.

```
O(n)
```

# Solution 2: Bit Manipulation (In-Place)

## Intution

The constraints state:

```
1 <= nums[i] <= 1000
```

Since:

```
1000 < 2^10
```

every number can be represented using **10 bits**.

Instead of creating another array, temporarily store **two numbers inside one integer**.

For every pair:

- Keep the first number in the lower 10 bits.
- Store the second number in the higher bits using a left shift.

```
Combined Number

| second number | first number |
      << 10          10 bits
```

Later, traverse the array backwards to avoid overwriting values:

- Extract the second number using right shift (`>> 10`).
- Extract the first number using a bitmask (`& ((1 << 10) - 1)`).
- Place them in their shuffled positions.

**In one line:** Pack two numbers into one integer using bit manipulation, then unpack them in reverse order to achieve an in-place shuffle.

## Algorithm

1. Traverse the second half of the array.
2. Pack each pair into the corresponding first-half element.
3. Create a mask containing the lower 10 bits.
4. Traverse the packed values from right to left.
5. Extract both numbers.
6. Place them into their shuffled positions.
7. Return the modified array.

## Code

```py
class Solution:
    def shuffle(self, nums: List[int], n: int) -> List[int]:
        for idx in range(n, 2 * n):
            nums[idx - n] |= (nums[idx] << 10)

        ones = (1 << 10) - 1

        for idx in range(n - 1, -1, -1):
            secondnumber = nums[idx] >> 10
            firstnumber = nums[idx] & ones

            nums[idx * 2 + 1] = secondnumber
            nums[idx * 2] = firstnumber

        return nums
```

## Time Complexity

The array is traversed twice.

```
O(n)
```

## Space Complexity

Only a few integer variables are used.

```
O(1)
```

## Key Takeaways

- Interleaving two arrays is straightforward using an auxiliary array.
- If constraints limit the value range, multiple numbers can sometimes be packed into a single integer.
- Bit manipulation (`<<`, `>>`, `&`, `|`) is useful for in-place transformations.
- Traversing backwards prevents overwriting packed values before they are decoded.
